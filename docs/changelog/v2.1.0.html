Anori v2.1.0

可调节的 Widget 背景、更顺滑的启动体验，以及一次彻底的本地化瘦身
2026-08-21

破坏性变更

  1. Breaking 下线 Anori Plus 与云同步：账号、设备同步、支付订阅、同步标签页小组件全部移除；本地 Widget、文件夹、设置与备份不受影响，旧备份中残留的云字段会在导入时被自动过滤。

新功能

  1. 全局 Widget 背景透明度：在主题设置中新增一个滑块，统一调节所有 Widget 卡片的背景不透明度，文字、图标与控件始终保持完全清晰。
  2. 首屏背景内联：把默认主题背景写入新标签页 HTML 头部，样式表加载前不再出现白色闪烁。
  3. 启动入口门控：通过 __anoriEntranceReady 把卡片渲染推迟到首帧就绪，入场动画不再被加载遮罩盖住。
  4. 图标选择器缓存：替换掉 React Query 之后，为 Iconify 图标列表补回模块级缓存，切换筛选时不再重复请求或短暂闪空。

修复

  1. 设置面板：修复主题屏幕缺少 Slider 导入导致左下角设置弹窗无法打开的问题。
  2. 启动白屏：默认主题颜色改为在 preload.js 同步注入，并在全局 CSS 中补齐暗色/亮色兜底，F5 不再先闪白页再出现 Anori。
  3. 入场动画：卡片在加载遮罩淡出后再挂载，原本被遮住的 stagger 入场动画恢复可见。
  4. 翻译完整度：补齐 14 个主题相关的本地化键，并清理 19 种语言中残留的 67 个云端/Plus 文案，CI 的 strict 翻译检查保持通过。
  5. 存储兼容：旧版 storage 迁移不再带入 cloudAccount，从老备份恢复时也会过滤已删除的云相关键，避免凭据残留。
备注
本次更新不主动清理你本地已有的旧云字段；它们只是不再被代码读取。想彻底清除，可在浏览器扩展管理中删除 Anori 的本地存储后再导入一次备份。
