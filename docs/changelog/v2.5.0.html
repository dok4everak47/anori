Anori v2.5.0

悬停侧边栏换成常驻左下角的浮动 Dock，所有 widget 都能更自由地拉大
2026-08-22

破坏性变更

  1. 设置移除侧边栏方向：原「自动 / 纵向 / 横向」选项已移除，Dock 固定显示在左下角。无需迁移，原设置不再生效；为兼容云同步与备份，底层字段予以保留。

新功能

  1. 浮动 Dock：以 macOS 风格的浮动 Dock 栏取代原先需悬停才出现的侧边栏，常驻左下角，文件夹切换与「更新 / 编辑 / 设置」入口一触即达，无需再悬停等待展开。
  2. Widget 四角拉伸：编辑模式下所有 widget 都可拖动四个角调整尺寸，按网格吸附到合适行列，限制在当前可见网格内，并自动推开会重叠的 widget。

修复

  1. 右侧贴边：编辑或拉大 widget 时，网格现在按实际可见区域计算列数，最右侧 widget 可以贴近可见边缘而不会撑出额外滚动区域。
  2. 竖屏壁纸压扁：竖屏照片在「适合屏幕」下不再因布局变化被横向拉伸，背景始终按真实比例居中。

这次调整保持固定的新标签页布局：所有新增、拖动和拉伸都被限制在当前可见网格内，小尺寸 widget 仍可整齐摆放，编辑完成后退出编辑模式即可恢复清爽界面。
