Anori v2.6.0

自定义主题支持多张壁纸，每次打开新标签随机切换，每张可独立调整模糊、裁剪与填充色。
2026-08-23

新功能

  1. 多壁纸主题：在主题编辑器中为同一个自定义主题添加任意多张壁纸，顶部缩略图条可在不同壁纸之间切换编辑。
  2. 每张独立设置：每张壁纸单独保存模糊度、填充方式（适应 / 铺满 / 平铺）、对齐位置与背景填充色，不再共用同一套裁剪。
  3. 新标签随机切换：每次打开新标签页，从当前主题的壁纸中随机挑选一张，并自动避开上一次显示的那张。
  4. 右下角下一张按钮：多壁纸主题的新标签页右下角出现刷新按钮，点击按顺序切到下一张壁纸，单壁纸主题不显示。
  5. 主题卡片角标：主题列表中多壁纸主题的缩略图左上角显示壁纸数量，方便一眼识别。

修复

  1. 启动壁纸：修复早期预加载脚本不认识多壁纸字段，导致刷新后总是显示第一张、并使用第一张的裁剪设置的问题。
  2. 壁纸清理：删除单张壁纸或整个主题时，对应的原始与模糊化文件会一并从存储中清理，不再留下孤立文件。

升级后原有单张壁纸主题会自动迁移为只含一张壁纸的新结构，原有模糊、裁剪、对齐与填充色设置完整保留；内置主题保持单图不变。
