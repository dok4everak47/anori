Anori v2.2.0

Widget 背景升级为 macOS Tahoe 风格的液态玻璃，性能门控保证不卡顿
2026-08-21

新功能

  1. 液态玻璃背景：将透明度滑到 100% 以下，Widget 会自动启用 backdrop-filter 模糊并提亮背后的壁纸，叠加边缘高光，呈现 macOS Tahoe 式的液态玻璃质感；文字与图标仍保持完全清晰。
  2. 满不透明零成本：透明度为 100% 时不启用任何 backdrop-filter，不产生额外合成层，性能与以往一致。
  3. 拖动与调整时暂停模糊：拖拽或调整 Widget 尺寸期间，玻璃模糊会临时关闭，避免位置变化反复重算导致卡顿，松手后恢复。

修复

  1. 背景渲染：修复滑块拉到 0% 时背景完全消失的问题，现在仍会保留玻璃模糊与边缘高光，而不是空白卡片。
备注
想看到液态玻璃效果，请在「主题」设置里把「Widget 背景透明度」调到 95% 或更低；越低越通透。该效果依赖浏览器的 backdrop-filter，Chrome 与 Firefox 均已支持。
