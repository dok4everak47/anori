Anori v2.3.0

移除全部非英文界面语言与翻译基础设施，界面统一为英文
2026-08-21

破坏性变更

  1. 界面统一为英文：删除 19 种非英文界面翻译，界面仅保留英文；已选择其他语言的用户会自动切回英文。
  2. 扩展商店本地化移除：删除非英文 _locales 文件夹，扩展名称与描述统一显示英文。
  3. 翻译基础设施移除：删除 translations-manager、fingerprints、notes 与 translations:* 脚本，不再支持自动翻译流程。

修复

  1. 动态导入：移除 moment locale 的动态导入，消除部分用户遇到的“Failed to fetch dynamically imported module”加载错误。
  2. 预提交钩子：清理已移除的 translations:status 调用，避免每次提交时的告警。
备注
如需使用其他语言，可自行 fork 仓库并在 src/translations/en.json 基础上添加翻译。i18next 与 react-i18next 仍保留，键值解析机制不变。
