Anori v2.7.0

Top Sites widget 可手动添加固定站点，支持编辑、排序与自定义图标，不再只能依赖浏览器自动推荐。
2026-08-25

新功能

  1. 手动添加固定站点：Top Sites 网格末尾常驻一个虚线「+」格子，点击即可输入网址与标题，把任意站点固定在最前面，不再受浏览器推荐限制。
  2. 编辑固定站点：进入编辑模式后，每个固定站点左上角出现铅笔按钮，可随时修改网址、标题或自定义图标。
  3. 排序固定站点：编辑模式下，固定站点左下角与右下角出现方向键，可在网格中前移 / 后移（纵向 widget 对应上移 / 下移），顺序随同步与备份保留。
  4. 自定义图标：在添加或编辑弹窗中填写图标 URL，该站点将使用指定图标展示；留空则继续使用浏览器自带的 favicon。
  5. 固定站点标识：非编辑模式下，固定站点右下角显示一枚书签角标，与浏览器自动推荐站点一眼区分。

修复

  1. 隐藏站点：浏览器自动推荐站点的「×」继续将对应网址加入黑名单；固定站点的「×」改为直接从固定列表移除，两者互不影响。

升级后原有黑名单设置保持不变，新增的固定站点列表为空数组，无需任何手动迁移；浏览器推荐站点会自动补齐未被固定与「+」按钮占用的位置。
